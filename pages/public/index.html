Create Text Line

Create batch SQL queries or text from placeholders. Put values in the columns below and each {} is filled in column order.

How to use

  1. Type a query or text template with {} placeholders.
  2. Put values into the columns, one value per line. Use + to add and × to remove.
  3. Choose Create Lines.

Placeholders are filled from columns in order. Each output row uses the matching input row from every column. If a column is shorter, its last value is reused. Blank lines are ignored and single quotes are doubled for SQL literals.

Request more features

Need another column, a different placeholder style, saved presets, or something else? Open an issue on GitHub — issues can be requests too: github.com/myridia/textmaker/issues.

About

TextMaker is a small client-side tool for generating batch SQL queries and repeated text. It runs entirely in the browser, needs no build step, and is released under GPL-3.0.

Developers are welcome at github.com/myridia/textmaker.
